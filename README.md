# The Word — Bible

A mobile-first Bible reading PWA starter. Bible chapters are loaded from bible-api.com in the King James Version (internet connection required for chapter loading). Saved verses and theme preference are stored locally in the browser.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of your repository.
2. Open the repository's **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for GitHub Pages to publish the site.

## Install on Android
Open the published HTTPS site in Chrome, tap the three-dot menu, and choose **Add to Home screen** or **Install app**.

Bible text is fetched from the public bible-api.com service (KJV). An internet connection is needed to load chapters.
